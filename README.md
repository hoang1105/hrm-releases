# ANPHABE HRM – bản phát hành

Repo này chỉ chứa các bản phát hành của ANPHABE HRM (phần mềm quản trị nhân sự của Anphabe).

Cài lần đầu: tải `AnphabeHRM-Setup-<phiên bản>.exe` ở [release mới nhất](https://github.com/hoang1105/hrm-releases/releases/latest) và chạy.
Sau đó ứng dụng tự cập nhật từ repo này.
